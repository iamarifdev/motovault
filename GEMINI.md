# MotoVault contributor instructions

Read and follow `AGENTS.md`, `docs/engineering/ai-workflow.md`,
`docs/roadmap/ARCHITECTURE-CONTRACT.md`, `docs/engineering/localization-style.md`
and the relevant task and phase in `docs/roadmap/roadmap.json`. The architecture contract
is shared across contributors and assistants. Preserve existing user changes and
follow the roadmap, evidence, design, copy, data, shell and permission rules in
`AGENTS.md`. Do not create per-feature skills/agents or assume a proposed module
or quality gate already exists.
