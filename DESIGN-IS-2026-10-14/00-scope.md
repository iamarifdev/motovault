# MotoVault whole-app UI/UX audit

Scope: active native Compose Multiplatform app in this repository, including onboarding/model selection, garage, maintenance/components/history, fuel, document capture/import/review/detail, inspection, appearance, reminders, export and recovery.

Primary user: native Bangladeshi motorcycle owners. Easy, modern Bangla is the first UI language; English is secondary. Primary tasks: know what needs attention, record ownership activity, keep and quickly show documents.

Audience correction: evaluate language and visual hierarchy around Bangla reading, familiar local terms, Bangladesh date/currency conventions and varying technical confidence. English-first screens do not satisfy the intended audience simply because the catalogue includes local motorcycles.

Method: read-only product audit with source citations, existing screenshot inspection and live UI where available. Historical screenshots are not proof of current runtime. No implementation changes. Audit artifacts are the only added files.

Constraints: retain native Android/iOS context and current brand identity; evaluate accessibility, first use, repeated use, trust, engagement and adverse states. No competitor study or user testing has been supplied. Scores are expert heuristics, not measured user satisfaction.
