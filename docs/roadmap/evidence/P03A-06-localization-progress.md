The named `FuelDefaults` policy now owns the existing octane/petrol values without changing their stored representation. `:composeApp:testDebugUnitTest :composeApp:compileKotlinIosSimulatorArm64 --offline` passed after these changes. These later sources have not yet been tested in a running app; the earlier screenshots apply only to the hashes listed at the top of this report.

The Android unit suite and nine focused iOS coordinator tests passed; the resource parity suite passed 24 checks, and Android and iOS simulator compilation succeeded.
