# P05-04 iOS runtime: renewal state, reminder and archive

Environment: iOS 27 iPhone 18 Pro Max simulator (`iPhone19,3`,
`50709DF0-FEA9-4B34-9DE6-6172D868875D`), ad hoc signed debug
`com.motovault.app.privacyprobe` build. No physical iPhone was used.

## Build

```text
xcodebuild -project iosApp/MotoVault.xcodeproj -scheme MotoVault -configuration Debug \
  -destination 'platform=iOS Simulator,id=50709DF0-FEA9-4B34-9DE6-6172D868875D' \
  -derivedDataPath build/ios-p05 build \
  PRODUCT_BUNDLE_IDENTIFIER=com.motovault.app.privacyprobe \
  CODE_SIGN_IDENTITY=- CODE_SIGNING_ALLOWED=YES CODE_SIGNING_REQUIRED=YES
```

App binary SHA-256:
`07ff01fe28c5f83e672b4b995c46da690a5fa511f19d055bb0c1098060584d2a`.

## Run

Launched with `--motovault-storage-probe --motovault-storage-probe-run=p05-renewal-final-20261105`.
The result file is retained verbatim at
[P05-ios-native-probe.txt](P05-ios-native-probe.txt).

```text
PASS 22 native iOS storage checks
```

The new check `native-renewal-event-fee-reminder-and-round-trip` verifies on the
simulator:

- previous and new expiry on the renewal event;
- document revision 1 and the owner-paid fee;
- the `document_fee` ledger entry linked to the document and renewal;
- checklist reset after renewal;
- a reminder-plan event for the new expiry;
- the backup-document mapping preserves the renewal and fee;
- the renewed state survives a JSON round-trip.

## Limits

- This is a native state/archive/reminder probe, not a screenshot-driven iOS
  sheet. The production iOS renewal sheet is represented by the v3 prototype and
  shares the same Compose implementation compiled for iOS; P08-05 keeps runtime
  localization evidence open.
- The iOS receipt picker's system file selection is not driven by the probe.
- No physical iPhone was used.
